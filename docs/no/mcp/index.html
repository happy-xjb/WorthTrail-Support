Model Context Protocol · macOS · Kun localhost

Spør AI om nettoformuen din — uten å laste den opp til skyen.

WorthTrail for Mac har en innebygd lokal MCP-server (Model Context Protocol) over Streamable HTTP. Koble til Claude Code, Claude Desktop, Codex eller en annen kompatibel klient for å spørre om porteføljen og kun lagre endringer etter godkjent forhåndsvisning.

Skaff WorthTrail på Mac Les FAQ

Tilkoblingsspesifikasjoner

Egenskap Verdi
Transport Streamable HTTP (kun lokal loopback)
Standard endepunkt http://127.0.0.1:47821/mcp (port kan endres i Innstillinger, 1024–65535)
Autentisering Authorization: Bearer <token> (lagret i macOS Nøkkelring; kan nullstilles når som helst)
Tilgjengelighet Kjører kun mens WorthTrail er åpen på Mac og Agenttilgang er skrudd på
Pris Inkludert i gratisplanen (ingen betalingsmur på MCP; grensen på 10 poster gjelder nye eiendeler)

Slik kobler du til

Åpne WorthTrail på Mac → Innstillinger → Agenttilgang, slå på lokal agenttilgang og kopier oppsettsprompten eller Bearer-tokenet ditt.

Claude Code

claude mcp add --transport http --scope user worthtrail http://127.0.0.1:47821/mcp \
  --header "Authorization: Bearer YOUR_TOKEN"

Claude Desktop (~/.claude.json)

{
  "mcpServers": {
    "worthtrail": {
      "type": "http",
      "url": "http://127.0.0.1:47821/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Codex (~/.codex/config.toml)

[mcp_servers.worthtrail]
url = "http://127.0.0.1:47821/mcp"
http_headers = { "Authorization" = "Bearer YOUR_TOKEN" }

Hva AI-agenter kan spørre om og gjøre

Leseverktøy (aktive når Agenttilgang er på)

  • Nåværende nettoformue, totale eiendeler, forpliktelser, kostpris og dagens endring (get_net_worth)
  • Åpne posisjoner etter kategori eller valuta: aksjer, ETF-er, krypto, opsjoner, tidsinnskudd og manuelle eiendeler (list_positions, list_liabilities)
  • Historiske øyeblikksbilder og daglig fordeling per beholdning (get_snapshots, get_snapshot_detail)
  • Periodeytelse, pengevektede avkastningskurver og daglig resultat per beholdning (get_performance, get_daily_earnings)
  • Utbytte, gjentakende planer, transaksjonshistorikk og FIRE-prognoser

Skriveverktøy (egen bryter)

  • Av som standard — å slå på lesetilgang aktiverer aldri skriving automatisk.
  • Totrinnsbekreftelse: første kall returnerer en lesbar forhåndsvisning og en kortvarig kode. Endringen lagres først når du godkjenner og agenten sender andre kall med koden.
  • Støtter handler, beholdningsjusteringer, eiendeler, forpliktelser, planer og angre — med innebygd endringslogg i Innstillinger.

Eksempelspørsmål

  • «Hva er min nåværende nettoformue i NOK, og hvor mye har porteføljen endret seg denne måneden?»
  • «Hvilke beholdninger har bidratt mest til resultatet mitt de siste 90 dagene?»
  • «Hvor mye årlig utbytte og renteinntekt forventes jeg å få, og hvor stor del av FIRE-utgiftene dekker det?»
  • «Lag en forhåndsvisning for kjøp av 10 AAPL-aksjer til $225 i dag og vent på min godkjenning før du lagrer.»

Sikkerhetsmodell

  • Kun localhost: lytter utelukkende på 127.0.0.1 — aldri eksponert mot lokalt nettverk eller internett.
  • Respekterer applås: forespørsler blokkeres når WorthTrail er låst.
  • Beskyttelse mot prompt-injeksjon: verktøyinstruksjoner pålegger agenter å behandle navn, symboler, tagger og notater kun som data, aldri som kommandoer.
  • Umiddelbar tilbakekalling: slå av bryteren, bytt port eller nullstill nøkkelringtoken for å koble fra alle klienter øyeblikkelig.
