Fakta & svar

Ofte stilte spørsmål

Rette svar om personvern, eiendelstyper, priser og den lokale Mac MCP-serveren.

Krever WorthTrail tilkobling til bank- eller meglerkonto?

Nei. WorthTrail er bevisst laget uten bankinnlogging og uten Plaid. Du registrerer beholdninger, kontanter, tidsinnskudd og forpliktelser direkte, mens offentlige kurser og valutakurser oppdateres automatisk.

Hvor lagres porteføljedataene mine?

Dataene lagres lokalt på enheten via Apple SwiftData. Valgfri synkronisering mellom enheter bruker utelukkende din private Apple iCloud-database (CloudKit). Utvikleren driver ingen server som mottar porteføljen din, og appen inneholder ingen reklame eller analyse-SDK-er.

Hvordan fungerer prisene? Finnes det et engangskjøp?

Ja. Gratisversjonen omfatter alle funksjoner opptil 10 poster (eiendeler, kontanter og forpliktelser samlet). WorthTrail Pro fjerner kun 10-postersgrensen: US$0,99/mnd, US$5,99/år eller US$12,99 engangskjøp (lokale NOK-priser i App Store).

Hvilke eiendelstyper og markeder støttes?

WorthTrail dekker globale aksjer (USA, Norden, Europa, HK, CN, TW m.fl.), ETF-er, fond, kryptovaluta, opsjoner, tidsinnskudd, kontanter, manuelt verdsatte eiendeler (eiendom, gull, obligasjoner) og forpliktelser (boliglån, lån). Alle valutaer regnes automatisk om til din hovedvaluta.

Hvilke markedsdatakilder bruker WorthTrail?

Du kan aktivere, deaktivere og endre rekkefølge på kilder under Innstillinger > Datakilder og status, inkludert Yahoo Finance, Webull, Binance, OKX, Sina Finance, TWSE og ExchangeRate-API. Kun nødvendige symboler og valutaer sendes til aktiverte kilder.

Støtter WorthTrail utbytte, FIRE og rebalansering?

Ja. WorthTrail inneholder utbyttekalender med ex-dager og passiv inntekt etter skatt, utbyttevekst og konsentrasjon, tilpassbart FIRE-dashbord, gjentakende planer, aksjesplitt og rebalanseringskalkulator.

Hvordan fungerer den lokale Mac MCP-serveren?

På Mac tilbyr WorthTrail en valgfri lokal Streamable HTTP MCP-server (http://127.0.0.1:47821/mcp) med Bearer-token i macOS Nøkkelring. Koble til Claude Code, Claude Desktop eller Codex for å spørre om nettoformue, beholdninger, ytelse, utbytte og FIRE. Skriving er av som standard og krever alltid forhåndsvisning og bekreftelseskode. Se Mac MCP-guiden.

Kan jeg eksportere data eller ta lokale sikkerhetskopier?

Ja. Du kan eksportere passordbeskyttede, krypterte lokale sikkerhetskopier (og gjenopprette når som helst) samt Excel-arbeidsbøker (.xlsx) og PDF-rapporter.

Hvilke plattformer støttes?

WorthTrail er tilgjengelig på iPhone, iPad og Mac via Apple App Store på over 45 språk. Android- og nettversjon er foreløpig ikke tilgjengelig.
