Model Context Protocol · macOS · Только localhost

Спрашивайте ИИ о своём капитале — не загружая его в облако.

WorthTrail для Mac содержит встроенный локальный MCP-сервер (Model Context Protocol) поверх Streamable HTTP. Подключите Claude Code, Claude Desktop, Codex или любой совместимый клиент, чтобы анализировать портфель и вносить записи только после явного подтверждения предпросмотра.

Параметры подключения

Параметр Значение
Транспорт Streamable HTTP (только локальный loopback)
Адрес по умолчанию http://127.0.0.1:47821/mcp (порт настраивается в Настройках, 1024–65535)
Аутентификация Authorization: Bearer <token> (хранится в Связке ключей macOS; можно сбросить в любой момент)
Доступность Работает только пока WorthTrail открыт на Mac и включён Доступ агентов
Стоимость Включено в бесплатный тариф (без пейволла на MCP; лимит 10 позиций действует на добавление новых активов)

Как подключиться

Откройте WorthTrail на Mac → Настройки → Доступ агентов, включите локальный доступ и скопируйте готовый промпт настройки или Bearer-токен.

Claude Code

claude mcp add --transport http --scope user worthtrail http://127.0.0.1:47821/mcp \
  --header "Authorization: Bearer YOUR_TOKEN"

Claude Desktop (~/.claude.json)

{
  "mcpServers": {
    "worthtrail": {
      "type": "http",
      "url": "http://127.0.0.1:47821/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Codex (~/.codex/config.toml)

[mcp_servers.worthtrail]
url = "http://127.0.0.1:47821/mcp"
http_headers = { "Authorization" = "Bearer YOUR_TOKEN" }

Что умеют ИИ-агенты

Инструменты чтения (доступны при включении Доступа агентов)

  • Текущая чистая стоимость, общие активы, долги, стоимость приобретения и изменение за день (get_net_worth)
  • Открытые позиции по категориям и валютам: акции, ETF, крипто, опционы, вклады и произвольные активы (list_positions, list_liabilities)
  • Исторические снимки и ежедневная разбивка по активам (get_snapshots, get_snapshot_detail)
  • Доходность за период, взвешенные по деньгам кривые и дневная прибыль по позициям (get_performance, get_daily_earnings)
  • Дивиденды, регулярные планы, история операций и прогнозы FIRE

Инструменты записи (отдельный переключатель)

  • Выключены по умолчанию — включение чтения никогда не открывает запись автоматически.
  • Двухэтапное подтверждение: первый вызов возвращает читаемый предпросмотр и временный код. Изменение применяется только после вашего согласия и повторного вызова с этим кодом.
  • Поддержка сделок, корректировки позиций, активов, долгов, планов и отмены действий — с журналом изменений в Настройках.

Примеры вопросов

  • «Какова моя текущая чистая стоимость в USD и насколько изменился портфель за этот месяц?»
  • «Какие позиции внесли наибольший вклад в прибыль или убыток за последние 90 дней?»
  • «Какой годовой доход от дивидендов и процентов по вкладам ожидается и какую долю расходов FIRE он покрывает?»
  • «Покажи предпросмотр покупки 10 акций AAPL по $225 сегодня и дождись моего подтверждения перед записью.»

Модель безопасности

  • Только localhost: привязан строго к 127.0.0.1 — недоступен из локальной сети и интернета.
  • Учёт блокировки приложения: при заблокированном WorthTrail все запросы отклоняются.
  • Защита от prompt-инъекций: инструкции прямо предписывают агентам считать названия, тикеры, теги и заметки исключительно данными, а не командами.
  • Мгновенный отзыв доступа: выключите тумблер, смените порт или сбросьте токен в Связке ключей, чтобы сразу отключить всех клиентов.
