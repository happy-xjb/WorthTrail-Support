Model Context Protocol · macOS

Встроенный локальный MCP-сервер для Claude и Codex.

WorthTrail для Mac включает опциональный локальный Streamable HTTP MCP-сервер (http://127.0.0.1:47821/mcp) с Bearer-токеном в Связке ключей macOS. Задавайте ИИ-ассистенту вопросы о чистом капитале, позициях, доходности, дивидендах и прогрессе FIRE без загрузки портфеля в стороннее облако.

Безопасность по умолчанию: выключен изначально, слушает только localhost, работает в режиме чтения, пока вы сами не разрешите запись, а каждое изменение требует предпросмотра и кода подтверждения.
