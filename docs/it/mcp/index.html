Model Context Protocol · macOS · Solo localhost

Chiedi all’IA del tuo patrimonio netto senza caricarlo nel cloud.

WorthTrail per Mac integra un server locale MCP (Model Context Protocol) su Streamable HTTP. Collega Claude Code, Claude Desktop, Codex o altri client compatibili per consultare il portafoglio e registrare modifiche solo dopo approvazione esplicita dell’anteprima.

Ottieni WorthTrail su Mac Leggi le FAQ

Specifiche di connessione

Proprietà Valore
Trasporto Streamable HTTP (solo loopback locale)
Endpoint predefinito http://127.0.0.1:47821/mcp (porta configurabile in Impostazioni, 1024–65535)
Autenticazione Authorization: Bearer <token> (salvato nel Portachiavi macOS; rigenerabile in ogni momento)
Disponibilità Attivo solo quando WorthTrail è aperto su Mac e Accesso agenti è abilitato
Prezzo Incluso nel piano gratuito (nessun paywall su MCP; per aggiungere nuovi asset vale il limite di 10 voci)

Come connettersi

Apri WorthTrail su Mac → Impostazioni → Accesso agenti, abilita l’accesso locale e copia il prompt di configurazione o il token Bearer.

Claude Code

claude mcp add --transport http --scope user worthtrail http://127.0.0.1:47821/mcp \
  --header "Authorization: Bearer YOUR_TOKEN"

Claude Desktop (~/.claude.json)

{
  "mcpServers": {
    "worthtrail": {
      "type": "http",
      "url": "http://127.0.0.1:47821/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Codex (~/.codex/config.toml)

[mcp_servers.worthtrail]
url = "http://127.0.0.1:47821/mcp"
http_headers = { "Authorization" = "Bearer YOUR_TOKEN" }

Cosa possono interrogare e fare gli agenti IA

Strumenti di lettura (attivi con Accesso agenti)

  • Patrimonio netto attuale, totale asset, passività, costo di carico e variazione giornaliera (get_net_worth)
  • Posizioni aperte per categoria o valuta: azioni, ETF, cripto, opzioni, depositi e asset manuali (list_positions, list_liabilities)
  • Snapshot storici e dettaglio giornaliero delle posizioni (get_snapshots, get_snapshot_detail)
  • Prestazioni nel periodo, curve di rendimento ponderato e profitti giornalieri per titolo (get_performance, get_daily_earnings)
  • Dividendi, piani ricorrenti, storico operazioni e proiezioni FIRE

Strumenti di scrittura (interruttore separato)

  • Disattivati di default: abilitare la lettura non abilita mai automaticamente la scrittura.
  • Conferma in due passaggi: la prima chiamata restituisce un’anteprima leggibile e un codice temporaneo. La modifica viene applicata solo quando approvi e l’agente invia la seconda chiamata con quel codice.
  • Supporta operazioni, rettifiche di posizione, asset, passività, piani e annullamento, con registro delle modifiche in Impostazioni.

Esempi di domande

  • «Qual è il mio patrimonio netto attuale in EUR e quanto è variato il portafoglio questo mese?»
  • «Quali posizioni hanno contribuito di più al mio P&L negli ultimi 90 giorni?»
  • «A quanto ammontano i dividendi e gli interessi annuali stimati e quale quota delle mie spese FIRE coprono?»
  • «Mostrami l’anteprima per aggiungere 10 azioni AAPL a 225 $ oggi e attendi la mia conferma prima di registrarla.»

Modello di sicurezza

  • Solo localhost: in ascolto esclusivamente su 127.0.0.1, mai esposto su LAN o Internet.
  • Rispetta il blocco app: le richieste vengono bloccate se WorthTrail è bloccato.
  • Difesa da prompt injection: le istruzioni impongono agli agenti di trattare nomi, simboli, etichette e note solo come dati e mai come comandi.
  • Revoca immediata: spegni l’interruttore, cambia porta o rigenera il token nel Portachiavi per disconnettere subito tutti i client.
