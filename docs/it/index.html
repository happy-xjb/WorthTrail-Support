Dentro WorthTrail

Progettato per offrire chiarezza su ogni classe di asset.

Schermate iOS reali di WorthTrail: tipografia curata, numeri puliti e zero pubblicità.

Architettura della chiarezza

Pensato per il patrimonio nel lungo periodo, non per flussi caotici di spese.

Ogni posizione, valuta, dividendo e passività confluisce in un registro verificabile sotto il tuo completo controllo.

01 / PRIVACY

Local-first e iCloud privato

Salvato sul dispositivo con Apple SwiftData e sincronizzato solo tramite il tuo database privato CloudKit. Nessun server dello sviluppatore, nessun accesso bancario, niente pubblicità né SDK di tracciamento.

02 / MULTI-ASSET

Mercati globali e depositi a termine

Segui azioni (USA, Europa, HK, CN, TW e globali), ETF, fondi, cripto, opzioni, depositi a termine, liquidità, immobili e mutui con fonti dati configurabili.

03 / PIANIFICAZIONE

FIRE, dividendi e ribilanciamento

Stima la data FIRE e la sostenibilità del capitale, monitora dividendi e interessi netti, piani ricorrenti, frazionamenti ed esporta report in Excel o PDF.

Model Context Protocol · macOS

Server MCP locale integrato per Claude e Codex.

WorthTrail per Mac include un server MCP Streamable HTTP locale opzionale (http://127.0.0.1:47821/mcp) protetto da token Bearer nel Portachiavi macOS. Fai domande in linguaggio naturale su patrimonio netto, posizioni, prestazioni, dividendi e FIRE senza caricare il portafoglio su cloud esterni.

Sicurezza nativa: disattivato per impostazione predefinita, solo localhost, sola lettura finché non abiliti la scrittura, e ogni modifica richiede anteprima e codice di conferma.
