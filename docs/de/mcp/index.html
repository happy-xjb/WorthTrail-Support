Model Context Protocol · macOS · Nur Localhost

Fragen Sie KI nach Ihrem Nettovermögen – ohne es in eine Cloud hochzuladen.

WorthTrail für Mac bringt einen integrierten lokalen MCP-Server (Model Context Protocol) über Streamable HTTP mit. Verbinden Sie Claude Code, Claude Desktop, Codex oder andere kompatible Clients, um Ihr Portfolio abzufragen und Änderungen nur nach ausdrücklicher Vorschau zu bestätigen.

Verbindungsspezifikationen

Eigenschaft Wert
Transport Streamable HTTP (ausschließlich lokales Loopback)
Standard-Endpunkt http://127.0.0.1:47821/mcp (Port in den Einstellungen konfigurierbar, 1024–65535)
Authentifizierung Authorization: Bearer <token> (im macOS-Schlüsselbund gespeichert; jederzeit zurücksetzbar)
Verfügbarkeit Läuft nur, solange WorthTrail auf dem Mac geöffnet und der Agent-Zugriff aktiviert ist
Preis Im kostenlosen Tarif enthalten (keine Bezahlschranke für MCP; für neue Positionen gilt das 10-Positionen-Limit)

So verbinden Sie Ihren Client

Öffnen Sie WorthTrail auf dem Mac → Einstellungen → Agent-Zugriff, aktivieren Sie den lokalen Zugriff und kopieren Sie Ihren persönlichen Einrichtungs-Prompt oder das Bearer-Token.

Claude Code

claude mcp add --transport http --scope user worthtrail http://127.0.0.1:47821/mcp \
  --header "Authorization: Bearer YOUR_TOKEN"

Claude Desktop (~/.claude.json)

{
  "mcpServers": {
    "worthtrail": {
      "type": "http",
      "url": "http://127.0.0.1:47821/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Codex (~/.codex/config.toml)

[mcp_servers.worthtrail]
url = "http://127.0.0.1:47821/mcp"
http_headers = { "Authorization" = "Bearer YOUR_TOKEN" }

Was KI-Agenten abfragen und ausführen können

Lese-Tools (aktiv bei eingeschaltetem Agent-Zugriff)

  • Aktuelles Nettovermögen, Gesamtvermögen, Verbindlichkeiten, Anschaffungskosten und Tagesveränderung (get_net_worth)
  • Offene Positionen nach Kategorie oder Währung inkl. Aktien, ETFs, Krypto, Optionen, Festgeld und benutzerdefinierter Werte (list_positions, list_liabilities)
  • Historische Snapshots und tägliche Bestandsaufschlüsselung (get_snapshots, get_snapshot_detail)
  • Zeitraum-Wertentwicklung, geldgewichtete Renditekurven und Tagesgewinne je Position (get_performance, get_daily_earnings)
  • Dividenden, Sparpläne, Transaktionshistorie und FIRE-Prognosen

Schreib-Tools (separater Opt-in-Schalter)

  • Standardmäßig deaktiviert – das Aktivieren von Lesezugriff schaltet niemals automatisch Schreibrechte frei.
  • Zweistufige Bestätigung: Der erste Aufruf liefert eine lesbare Vorschau samt kurzlebigem Bestätigungscode. Erst nach Ihrer Freigabe führt der zweite Aufruf mit diesem Code die Änderung aus.
  • Unterstützt Käufe/Verkäufe, Bestandsanpassungen, Vermögenswerte, Verbindlichkeiten, Sparpläne und Rückgängigmachen – mit integriertem Änderungsprotokoll.

Beispielfragen für Ihren KI-Assistenten

  • „Wie hoch ist mein aktuelles Nettovermögen in EUR und wie stark hat sich mein Portfolio diesen Monat verändert?“
  • „Welche Positionen haben in den letzten 90 Tagen am stärksten zu meinem Gewinn oder Verlust beigetragen?“
  • „Wie viel jährliche Dividenden und Festgeldzinsen erwarte ich und welchen Anteil meiner FIRE-Ausgaben decken sie?“
  • „Erstelle eine Vorschau für den Kauf von 10 AAPL-Aktien zu $225 heute und warte vor dem Speichern auf meine Freigabe.“

Sicherheitsmodell

  • Reine Localhost-Bindung: Lauscht nur auf 127.0.0.1 – nicht im LAN oder Internet erreichbar.
  • App-Sperre wird respektiert: Ist WorthTrail gesperrt, werden alle Anfragen blockiert.
  • Schutz vor Prompt-Injection: Tool-Hinweise weisen Agenten an, Benutzernamen, Symbole, Etiketten und Notizen strikt als Daten und niemals als Befehle zu behandeln.
  • Sofortiger Widerruf: Schalter deaktivieren, Port ändern oder Schlüsselbund-Token zurücksetzen trennt sofort alle Clients.
