Model Context Protocol · macOS · Vain localhost

Kysy tekoälyltä nettovarallisuudestasi — lataamatta sitä pilveen.

WorthTrail Macille sisältää sisäänrakennetun paikallisen MCP (Model Context Protocol) -palvelimen Streamable HTTP:n yli. Yhdistä Claude Code, Claude Desktop, Codex tai muu yhteensopiva asiakas kysyäksesi salkustasi ja kirjataksesi muutoksia vasta hyväksyttyäsi esikatselun.

Hanki WorthTrail Macille Lue UKK

Yhteystiedot ja tekniset tiedot

Ominaisuus Arvo
Siirtotapa Streamable HTTP (vain paikallinen loopback)
Oletusosoite http://127.0.0.1:47821/mcp (portti muutettavissa Asetuksissa, 1024–65535)
Todennus Authorization: Bearer <token> (tallennettu macOS-avainnippuun; nollattavissa milloin tahansa)
Saatavuus Käynnissä vain kun WorthTrail on auki Macissa ja Agenttien käyttöoikeus on päällä
Hinnoittelu Sisältyy ilmaisversioon (ei maksumuuria MCP:lle; 10 kohteen raja koskee uusien kohteiden lisäämistä)

Näin yhdistät

Avaa WorthTrail Macissa → Asetukset → Agenttien käyttöoikeus, kytke paikallinen käyttöoikeus päälle ja kopioi asennuskehotteesi tai Bearer-tunnisteesi.

Claude Code

claude mcp add --transport http --scope user worthtrail http://127.0.0.1:47821/mcp \
  --header "Authorization: Bearer YOUR_TOKEN"

Claude Desktop (~/.claude.json)

{
  "mcpServers": {
    "worthtrail": {
      "type": "http",
      "url": "http://127.0.0.1:47821/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Codex (~/.codex/config.toml)

[mcp_servers.worthtrail]
url = "http://127.0.0.1:47821/mcp"
http_headers = { "Authorization" = "Bearer YOUR_TOKEN" }

Mitä tekoälyagentit voivat kysyä ja tehdä

Lukutyökalut (käytössä kun Agenttien käyttöoikeus on päällä)

  • Nykyinen nettovarallisuus, kokonaisvarat, velat, hankintameno ja päivämuutos (get_net_worth)
  • Avoimet positiot luokittain tai valuutoittain: osakkeet, ETF:t, krypto, optiot, talletukset ja manuaaliset kohteet (list_positions, list_liabilities)
  • Historiatilannekuvat ja päiväkohtaiset omistuserittelyt (get_snapshots, get_snapshot_detail)
  • Ajanjakson suorituskyky, rahapainotetut tuottokäyrät ja päivätuotot kohteittain (get_performance, get_daily_earnings)
  • Osingot, toistuvat suunnitelmat, tapahtumahistoria ja FIRE-ennusteet

Kirjoitustyökalut (erillinen kytkin)

  • Pois päältä oletuksena — lukuoikeus ei koskaan avaa kirjoitusoikeutta automaattisesti.
  • Kaksivaiheinen vahvistus: ensimmäinen kutsu palauttaa luettavan esikatselun ja lyhytaikaisen vahvistuskoodin. Muutos tallentuu vasta hyväksyntäsi ja toisen kutsun jälkeen.
  • Tukee kauppoja, omistuskorjauksia, omaisuuseriä, velkoja, suunnitelmia ja kumoamista — sisäänrakennetulla muutoslokilla.

Esimerkkikysymyksiä

  • ”Mikä on nykyinen nettovarallisuuteni euroissa ja paljonko salkkuni on muuttunut tässä kuussa?”
  • ”Mitkä omistukset ovat vaikuttaneet eniten tulokseeni viimeisen 90 päivän aikana?”
  • ”Kuinka paljon vuotuisia osinkoja ja talletuskorkoja arviolta saan, ja kuinka suuren osan FIRE-menoistani ne kattavat?”
  • ”Näytä esikatselu 10 AAPL-osakkeen lisäämisestä hintaan $225 tänään ja odota vahvistustani ennen tallentamista.”

Tietoturvamalli

  • Vain localhost: kuuntelee ainoastaan osoitetta 127.0.0.1 — ei näy lähiverkkoon tai internetiin.
  • Noudattaa sovelluslukkoa: kaikki pyynnöt estetään, kun WorthTrail on lukittuna.
  • Suoja prompt-injektiolta: työkalujen ohjeet käskevät agentteja käsittelemään nimiä, symboleja, tunnisteita ja muistiinpanoja pelkkänä datana, ei koskaan käskyinä.
  • Välitön katkaisu: kytke asetus pois, vaihda portti tai nollaa avainnipun tunniste katkaistaksesi kaikki yhteydet heti.
