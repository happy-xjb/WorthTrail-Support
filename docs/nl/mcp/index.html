Model Context Protocol · macOS · Alleen localhost

Stel AI vragen over uw nettovermogen — zonder het naar een cloud te uploaden.

WorthTrail voor Mac bevat een ingebouwde lokale MCP-server (Model Context Protocol) via Streamable HTTP. Koppel Claude Code, Claude Desktop, Codex of elke compatibele client om uw portefeuille op te vragen en wijzigingen pas na goedkeuring vast te leggen.

Verbindingsspecificaties

Eigenschap Waarde
Transport Streamable HTTP (alleen lokale loopback)
Standaard eindpunt http://127.0.0.1:47821/mcp (poort instelbaar in Instellingen, 1024–65535)
Authenticatie Authorization: Bearer <token> (opgeslagen in macOS-sleutelhanger; altijd te vernieuwen)
Beschikbaarheid Actief zolang WorthTrail open is op de Mac en Agenttoegang is ingeschakeld
Prijs Inbegrepen in de gratis versie (geen betaalmuur op MCP; de limiet van 10 items geldt voor nieuwe bezittingen)

Verbinding maken

Open WorthTrail op Mac → Instellingen → Agenttoegang, zet lokale agenttoegang aan en kopieer uw installatieprompt of Bearer-token.

Claude Code

claude mcp add --transport http --scope user worthtrail http://127.0.0.1:47821/mcp \
  --header "Authorization: Bearer YOUR_TOKEN"

Claude Desktop (~/.claude.json)

{
  "mcpServers": {
    "worthtrail": {
      "type": "http",
      "url": "http://127.0.0.1:47821/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Codex (~/.codex/config.toml)

[mcp_servers.worthtrail]
url = "http://127.0.0.1:47821/mcp"
http_headers = { "Authorization" = "Bearer YOUR_TOKEN" }

Wat AI-agents kunnen opvragen en doen

Leestools (actief zodra Agenttoegang aan staat)

  • Huidig nettovermogen, totale bezittingen, schulden, aankoopwaarde en dagverandering (get_net_worth)
  • Open posities per categorie of valuta: aandelen, ETF's, crypto, opties, deposito's en handmatige bezittingen (list_positions, list_liabilities)
  • Historische snapshots en dagelijkse uitsplitsing per positie (get_snapshots, get_snapshot_detail)
  • Periodeprestaties, geldgewogen rendementscurves en dagresultaten per belegging (get_performance, get_daily_earnings)
  • Dividenden, beleggingsplannen, transactiegeschiedenis en FIRE-prognoses

Schrijftools (aparte schakelaar)

  • Standaard uitgeschakeld — leestoegang aanzetten schakelt schrijven nooit automatisch in.
  • Tweestapsbevestiging: de eerste aanroep geeft een leesbaar voorbeeld en een tijdelijke bevestigingscode terug. De wijziging wordt pas doorgevoerd na uw akkoord via de tweede aanroep met die code.
  • Ondersteunt transacties, positiewijzigingen, bezittingen, schulden, plannen en ongedaan maken — met ingebouwd wijzigingslogboek.

Voorbeeldvragen

  • “Wat is mijn huidige nettovermogen in EUR en hoeveel is mijn portefeuille deze maand veranderd?”
  • “Welke posities droegen de afgelopen 90 dagen het meest bij aan mijn winst of verlies?”
  • “Hoeveel jaarlijkse dividenden en depositorente verwacht ik en welk deel van mijn FIRE-uitgaven dekt dit?”
  • “Maak een voorbeeld voor het toevoegen van 10 aandelen AAPL tegen $225 vandaag en wacht op mijn akkoord.”

Beveiligingsmodel

  • Alleen localhost: luistert uitsluitend op 127.0.0.1 — nooit bereikbaar vanaf uw netwerk of internet.
  • Respecteert app-vergrendeling: verzoeken worden geblokkeerd wanneer WorthTrail vergrendeld is.
  • Bescherming tegen prompt-injectie: toolinstructies verplichten agents om namen, symbolen, labels en notities strikt als gegevens te behandelen, nooit als opdrachten.
  • Direct intrekken: zet de schakelaar uit, wijzig de poort of reset het sleutelhangertoken om alle clients direct te verbreken.
