App 內支援與加密診斷檔案

在 WorthTrail 內前往 設定 > 聯絡與支援，即可一鍵寄信或於排查複雜報價與計算問題時匯出加密診斷檔案（.wtdiag）。

隱私提醒：一般信件中請勿附上銀行帳號、密碼、API 金鑰或敏感財務對帳單。診斷檔案僅於需要協助排查具體問題時再主動提供。

常見問題快速排解

多數常見問題都能直接在 App 的「設定」中快速解決。

市場資料、報價與自訂資產
  • 於 設定 > 資料來源與狀態 可測試各來源連線，測試呼叫的是與即時刷新相同的取價端點。
  • 部分資料來源（如 Yahoo Finance）在特定網路下可能受限，你可隨時調整順序或切換來源。
  • 針對不動產、黃金或未上市資產，可新增自訂資產並依需求更新估值。
持倉、持倉成本、股票分割與批次匯入
  • 記錄買入、賣出或部位調整時可填寫成交價與日期，以維持歷史股數與持倉成本準確。
  • 透過批次匯入可由 CSV 檔案或券商截圖快速匯入持倉（截圖 OCR 完全在裝置本機執行）。
  • 遇到股票分割或反分割時，使用資產詳情中的股票分割功能即可自動修正歷史股數與成本。
  • 歷史快照會建立淨資產曲線與損益日曆，並隨 iCloud 同步與本機加密備份一併保存。
iCloud 同步、加密備份與回復 Pro
  • 選用的多裝置同步僅透過個人 Apple iCloud（CloudKit 私有資料庫）進行，請確認各裝置登入相同 Apple 帳號。
  • 隨時可於設定匯出受密碼保護的本機加密備份，並於需要時還原。
  • 換機後若要回復 Pro 訂閱或永久買斷，請前往設定中的 Pro 畫面點選回復購買。
  • WorthTrail 無使用者帳號：刪除 App 即移除本機資料；iCloud 同步資料可於系統 iCloud 設定管理。
隱私鎖、小工具與 Mac MCP 排解
  • 點選概覽頁「淨資產」旁的眼睛圖示即可隱藏畫面金額。
  • 由 iOS 主畫面小工具庫新增 WorthTrail，其中隱私小工具僅顯示漲跌幅百分比與趨勢線。
  • 若 Mac MCP 無法連線，請確認 Mac 版 WorthTrail 已開啟且未上鎖、設定 > Agent 存取已開啟，且用戶端使用 http://127.0.0.1:47821/mcp 與最新 Bearer Token。
