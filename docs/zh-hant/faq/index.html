事實與解答

常見問題（FAQ）

關於隱私架構、支援的資產類別、收費方式與 Mac 本機 MCP 服務的直接解答。

WorthTrail 需要連結銀行或券商帳號嗎？

不需要。WorthTrail 專為不願交出銀行或券商憑證的使用者設計。你直接記錄持倉、現金、定存與負債，公開市場報價與匯率會自動刷新。

我的投資組合資料儲存在哪裡？

所有資料預設使用 Apple SwiftData 儲存在你的裝置本機。選用的跨裝置同步僅透過你個人的 Apple iCloud（CloudKit）私有資料庫進行。開發者不營運接收你資產的伺服器，App 內也無廣告或第三方分析 SDK。

定價如何計算？支援一次性永久買斷嗎？

支援。免費版開放全部功能，最多可記錄 10 項（資產、現金帳戶與負債合計）。WorthTrail Pro 僅移除 10 項上限：US$0.99/月、US$5.99/年或 US$12.99 一次性永久買斷（實際當地幣別價格以 App Store 為準）。

支援哪些資產類型、市場與幣別？

支援全球股票（美股、台股、港股、A股及國際市場）、ETF、基金、加密貨幣、期權、定期存款、現金、手動估值的自訂資產（房產、黃金、債券），以及房貸、貸款與信用卡等負債。所有外幣會自動換算為你的主幣別。

WorthTrail 使用哪些市場資料來源？

你可在 設定 > 資料來源與狀態 中自由啟用、停用與排序資料來源，包括 Yahoo Finance、Webull、Binance、OKX、新浪財經、TWSE（台灣證交所）與 ExchangeRate-API。查詢報價時僅會向已啟用的來源傳送必要代碼與幣別。

支援股利、FIRE 規劃與再平衡試算嗎？

全部支援。包含股利日曆（除息入帳與稅後被動收入）、成長與集中度分析、可自訂的 FIRE 儀表板（目標、覆蓋率、預計達成日與規劃年齡續航）、定投計劃、股票分割調整與目標配置再平衡試算。

Mac 本機 MCP 服務如何運作？

Mac 版內建可選的本機 Streamable HTTP MCP 服務（http://127.0.0.1:47821/mcp），以 macOS 鑰匙圈中的 Bearer Token 保護。可串接 Claude Code、Claude Desktop 或 Codex 查詢淨資產、持倉、損益、股利與 FIRE 指標。寫入預設關閉且每次皆須預覽與確認碼。詳見 Mac MCP 指南。

可以匯出資料或進行本機備份嗎？

可以。你可以匯出受密碼加密保護的本機備份檔案（隨時可還原），也能匯出 Excel（.xlsx）活頁簿與 PDF 報表以便歸檔或進一步分析。

支援哪些平台？

WorthTrail 支援 iPhone、iPad 與 Mac，可於 Apple App Store 下載，內建 45+ 種語言。目前暫不提供 Android 或網頁版。
