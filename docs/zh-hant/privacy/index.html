01

儲存在你裝置上的資料

WorthTrail 使用 Apple SwiftData 於你的裝置本機儲存資產、數量、持倉成本、負債、部位調整紀錄、股利、定投計劃、標籤、備註、設定與歷史快照。

開發者不營運任何接收、儲存或檢視你投資組合的後端伺服器，使用 WorthTrail 亦無需建立使用者帳號。

02

選用的個人 iCloud 私有同步

若你啟用 iCloud 同步，資料僅透過與你 Apple 帳號綁定的個人 Apple CloudKit 私有資料庫進行同步。

開發者無法存取你的 CloudKit 私有資料庫。同步資料之安全性遵循 Apple iCloud 的安全與隱私架構。

03

市場資料與匯率服務商

當你搜尋標的或刷新報價與匯率時，WorthTrail 僅會傳送必要的搜尋詞、代碼、來源識別碼與目標幣別給你於 設定 > 資料來源與狀態 中啟用的來源。

這些服務商（可能包括 Yahoo Finance、Webull、新浪財經、Binance、OKX、CoinGecko、CoinMarketCap、TWSE 與 ExchangeRate-API）可能接收你的 IP 位址與一般網路中繼資料，並依各自隱私權政策處理。WorthTrail 絕不傳送你的持股數量、持倉成本或帳戶餘額。

04

裝置端 OCR、小工具、備份與診斷檔案

截圖批次匯入（OCR）：你選取的截圖完全透過 Apple 裝置端 Vision 框架本機辨識，不會上傳至 WorthTrail 伺服器。

主畫面小工具：僅透過 App 私有 App Group 容器讀取顯示所需摘要；隱私小工具不包含任何金額。

本機備份與診斷檔案：受密碼保護的本機備份在匯出前即於裝置本機加密。選用的 .wtdiag 診斷檔案僅於你主動發起匯出時產生，並於離開 App 前加密。

05

Mac 本機 MCP 服務

Mac 版 WorthTrail 提供可選的本機 Streamable HTTP MCP 服務，嚴格綁定 127.0.0.1 並以 macOS 鑰匙圈 Bearer Token 驗證。此服務預設關閉、預設唯讀，寫入須另行開啟並經預覽與確認碼兩步驟驗證。

若你主動將本機 MCP 服務連線至外部 AI 用戶端（如 Claude Code、Claude Desktop 或 Codex），你指示該用戶端查詢的資料將遵循該用戶端與模型供應商自身的隱私權政策。

06

無廣告、無追蹤、購買與應用程式鎖

WorthTrail 不包含任何廣告、跨 App 追蹤或第三方分析 SDK。

App 內購買與訂閱全數由 Apple StoreKit 處理。Face ID 與 Touch ID 由 iOS/macOS 處理，WorthTrail 無法存取生物辨識資訊。密碼鎖僅於裝置本機儲存加鹽加密雜湊值。

07

資料刪除、政策更新與聯絡方式

刪除 WorthTrail 即可移除裝置本機所有資料；iCloud 同步資料可於 Apple iCloud 設定中管理或刪除；匯出的備份、Excel、PDF 或診斷檔案可於其儲存位置刪除。

當 App 行為有所變更時，本政策可能隨之更新。如有任何隱私疑問，請透過支援頁面聯絡我們，或寄信至 support@worthtrail.app。
