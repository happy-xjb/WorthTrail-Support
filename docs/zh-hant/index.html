真實介面一覽

克制清晰的排版，讓每筆資產與損益一目了然。

原生 Apple 體驗，無廣告、無彈窗干擾，直覺掌握跨市場持倉與長期淨值走勢。

產品架構

為長期財富管理而生，而非嘈雜的日常消費流水帳。

把分散在各家券商、銀行定存、加密錢包與不動產中的部位整合為可驗證的清晰帳本，完全由你掌控。

01 / 隱私架構

本機 SwiftData + 私人 iCloud

所有持倉、快照與備註預設儲存在你的裝置上，開啟同步後僅存入個人 Apple CloudKit 私有資料庫。開發者不營運儲存你資料的伺服器，零廣告、零第三方分析 SDK。

02 / 全資產覆蓋

全球市場與定期存款

支援美股、台股、港股、A股及全球股市、ETF、基金、加密貨幣、期權、定期存款、現金、房產黃金及各類負債，可自由配置報價資料來源。

03 / 長期規劃

FIRE、定投計劃與再平衡

提供可自訂年支出、提領率與規劃年齡的 FIRE 進度與資產續航估算、股利追蹤、定投計劃、股票分割調整，以及 Excel 與 PDF 報表匯出。

Model Context Protocol · macOS

Mac 版內建本機 MCP 服務，讓 AI 安全讀懂你的資產。

Mac 版 WorthTrail 內建可選的本機 Streamable HTTP MCP 服務（http://127.0.0.1:47821/mcp），以 macOS 鑰匙圈儲存的 Bearer Token 驗證。連線 Claude Code、Claude Desktop 或 Codex 後，即可直接詢問淨資產、持倉、損益、股利與 FIRE 進度，無需將投資組合上傳至第三方雲端。

預設安全設計：預設關閉、僅監聽本機迴路位址；讀寫權限分離，任何寫入都必須先回傳預覽與確認碼，經你同意後才會執行。
