Model Context Protocol · macOS · 僅限本機迴路

讓 AI 回答你的淨資產問題，而無需將帳本上傳至雲端。

Mac 版 WorthTrail 內建基於 Streamable HTTP 的本機 MCP（Model Context Protocol） 服務。連線 Claude Code、Claude Desktop、Codex 或其他相容用戶端，即可自然語言查詢資產，並可於明確預覽確認後記錄變更。

取得 Mac 版 WorthTrail 查看常見問題

連線規格

屬性 說明
傳輸協定 Streamable HTTP（僅監聽本機迴路位址）
預設端點 http://127.0.0.1:47821/mcp（可於設定修改連接埠，1024–65535）
驗證方式 Authorization: Bearer <token>（儲存於 macOS 鑰匙圈，隨時可重設）
運作條件 僅於 Mac 版 WorthTrail 開啟且已啟用「Agent 存取」時運行
收費說明 免費版完整包含（MCP 無付費牆；新增資產仍適用免費版 10 項上限）

如何連線

開啟 Mac 版 WorthTrail → 設定 → Agent 存取，啟用本機代理存取，並複製個人設定提示詞或 Bearer Token。

Claude Code

claude mcp add --transport http --scope user worthtrail http://127.0.0.1:47821/mcp \
  --header "Authorization: Bearer YOUR_TOKEN"

Claude Desktop (~/.claude.json)

{
  "mcpServers": {
    "worthtrail": {
      "type": "http",
      "url": "http://127.0.0.1:47821/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Codex (~/.codex/config.toml)

[mcp_servers.worthtrail]
url = "http://127.0.0.1:47821/mcp"
http_headers = { "Authorization" = "Bearer YOUR_TOKEN" }

AI 代理可以查詢與執行什麼

唯讀工具（開啟 Agent 存取即啟用）

  • 目前淨資產、總資產、負債、持倉成本與今日變動（get_net_worth）
  • 依分類或幣別列出全部持倉，含股票、ETF、加密貨幣、期權、定存與自訂資產（list_positions、list_liabilities）
  • 歷史快照與單日持倉明細（get_snapshots、get_snapshot_detail）
  • 期間損益表現、資金加權報酬曲線與依標的拆分的每日盈虧（get_performance、get_daily_earnings）
  • 股利、定投計劃、交易紀錄與 FIRE 預估

寫入工具（獨立手動開關）

  • 預設關閉——開啟唯讀存取絕不會自動開放寫入權限。
  • 兩步驟確認：首次工具呼叫僅回傳可讀預覽與短時效確認碼；唯有你同意並由 AI 攜帶該確認碼發起第二次呼叫才會真正寫入。
  • 支援記錄交易、持倉調整、新增資產/負債、定投計劃與復原操作，並於設定保留變更紀錄。

試著這樣提問

  • 「我目前的淨資產換算台幣是多少？這個月整體變化了多少？」
  • 「過去 90 天裡，哪幾檔持倉對我的損益貢獻最大？」
  • 「今年預計可領取多少稅後股利與定存利息？能覆蓋多少比例的 FIRE 年支出？」
  • 「先幫我預覽今天以 225 美元買入 10 股 AAPL 的紀錄，等我確認後再寫入。」

安全模型

  • 僅綁定本機迴路：僅監聽 127.0.0.1，不暴露於區網或網際網路。
  • 遵循應用程式鎖：當 WorthTrail 上鎖時，所有請求一律阻擋。
  • 提示詞注入防護：工具說明明確指示代理將名稱、代碼、標籤與備註嚴格視為純資料，絕非指令。
  • 即時撤銷連線：關閉開關、更換連接埠或重設鑰匙圈 Token，即可立即中斷所有用戶端。
