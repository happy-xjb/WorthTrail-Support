Model Context Protocol · macOS · Apenas localhost

Pergunte à IA sobre o seu património líquido sem o enviar para a nuvem.

O WorthTrail para Mac integra um servidor local MCP (Model Context Protocol) via Streamable HTTP. Ligue o Claude Code, Claude Desktop, Codex ou qualquer cliente compatível para consultar a carteira e registar alterações apenas após aprovação explícita.

Obter WorthTrail no Mac Ler perguntas frequentes

Especificações de ligação

Propriedade Valor
Transporte Streamable HTTP (apenas loopback local)
Endereço predefinido http://127.0.0.1:47821/mcp (porta configurável em Definições, 1024–65535)
Autenticação Authorization: Bearer <token> (guardado no Porta-chaves macOS; redefinível a qualquer momento)
Disponibilidade Ativo apenas enquanto o WorthTrail estiver aberto no Mac e o Acesso de agentes estiver ligado
Preço Incluído no plano gratuito (sem paywall no MCP; o limite de 10 itens aplica-se ao adicionar novos ativos)

Como ligar

Abra o WorthTrail no Mac → Definições → Acesso de agentes, ative o acesso local e copie o seu prompt de configuração ou token Bearer.

Claude Code

claude mcp add --transport http --scope user worthtrail http://127.0.0.1:47821/mcp \
  --header "Authorization: Bearer YOUR_TOKEN"

Claude Desktop (~/.claude.json)

{
  "mcpServers": {
    "worthtrail": {
      "type": "http",
      "url": "http://127.0.0.1:47821/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Codex (~/.codex/config.toml)

[mcp_servers.worthtrail]
url = "http://127.0.0.1:47821/mcp"
http_headers = { "Authorization" = "Bearer YOUR_TOKEN" }

O que os agentes IA podem consultar e fazer

Ferramentas de leitura (ativas ao ligar o Acesso de agentes)

  • Património líquido atual, ativos totais, passivos, custo de aquisição e variação diária (get_net_worth)
  • Posições abertas por categoria ou moeda: ações, ETFs, cripto, opções, depósitos e ativos personalizados (list_positions, list_liabilities)
  • Instantâneos históricos e detalhe diário das posições (get_snapshots, get_snapshot_detail)
  • Desempenho no período, curvas ponderadas pelo dinheiro e ganhos diários por ativo (get_performance, get_daily_earnings)
  • Dividendos, planos recorrentes, histórico de transações e projeções FIRE

Ferramentas de escrita (interruptor separado)

  • Desativadas por predefinição — ativar a leitura nunca ativa automaticamente a escrita.
  • Confirmação em dois passos: a primeira chamada devolve uma pré-visualização legível e um código temporário. A alteração só se aplica quando aprova e o agente envia a segunda chamada com esse código.
  • Permite registar operações, ajustes de posição, ativos, passivos, planos e anulações, com registo integrado em Definições.

Exemplos de perguntas

  • «Qual é o meu património líquido atual em EUR e quanto variou a minha carteira este mês?»
  • «Que posições mais contribuíram para os meus lucros e perdas nos últimos 90 dias?»
  • «Quanto rendimento anual em dividendos e juros de depósitos a prazo devo receber e que parte das minhas despesas FIRE cobre?»
  • «Mostra-me a pré-visualização para adicionar 10 ações de AAPL a $225 hoje e aguarda a minha confirmação antes de registar.»

Modelo de segurança

  • Apenas localhost: escuta exclusivamente em 127.0.0.1, nunca exposto na rede local nem na Internet.
  • Respeita o bloqueio da app: todos os pedidos são bloqueados enquanto o WorthTrail estiver bloqueado.
  • Proteção contra injeção de prompts: as instruções indicam aos agentes que tratem nomes, símbolos, etiquetas e notas estritamente como dados e nunca como comandos.
  • Revogação instantânea: desligue o interruptor, altere a porta ou redefina o token no Porta-chaves para desligar imediatamente todos os clientes.
