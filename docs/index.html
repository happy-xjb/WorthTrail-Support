Model Context Protocol · macOS

Built-in local MCP server for Claude & Codex.

WorthTrail for Mac runs an optional local Streamable HTTP MCP server (http://127.0.0.1:47821/mcp) authenticated via a Keychain Bearer token. Ask AI assistants plain-language questions about your net worth, holdings, returns, dividends, and FIRE progress without uploading your portfolio to a third-party cloud.

Safety by design: Off by default, localhost-only, read-only unless you explicitly enable writes, and every write requires a two-step preview and confirmation code.
