Model Context Protocol · macOS · Solo localhost

Pregunta a la IA por tu patrimonio neto sin subirlo a la nube.

WorthTrail para Mac integra un servidor local MCP (Model Context Protocol) sobre Streamable HTTP. Conecta Claude Code, Claude Desktop, Codex o cualquier cliente compatible para consultar tu cartera y registrar cambios solo tras aprobar la vista previa.

Especificaciones de conexión

Propiedad Valor
Transporte Streamable HTTP (solo loopback local)
Dirección predeterminada http://127.0.0.1:47821/mcp (puerto configurable en Ajustes, 1024–65535)
Autenticación Authorization: Bearer <token> (guardado en el Llavero de macOS; renovable en cualquier momento)
Disponibilidad Solo activo mientras WorthTrail esté abierto en Mac y el Acceso de agentes esté activado
Precio Incluido en el plan gratuito (sin muro de pago para MCP; rige el límite de 10 elementos al añadir activos)

Cómo conectarse

Abre WorthTrail en Mac → Ajustes → Acceso de agentes, activa el acceso local y copia tu prompt de configuración o tu token Bearer.

Claude Code

claude mcp add --transport http --scope user worthtrail http://127.0.0.1:47821/mcp \
  --header "Authorization: Bearer YOUR_TOKEN"

Claude Desktop (~/.claude.json)

{
  "mcpServers": {
    "worthtrail": {
      "type": "http",
      "url": "http://127.0.0.1:47821/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Codex (~/.codex/config.toml)

[mcp_servers.worthtrail]
url = "http://127.0.0.1:47821/mcp"
http_headers = { "Authorization" = "Bearer YOUR_TOKEN" }

Qué pueden consultar y hacer los agentes de IA

Herramientas de lectura (activas al encender Acceso de agentes)

  • Patrimonio neto actual, activos totales, deudas, coste de adquisición y variación diaria (get_net_worth)
  • Posiciones abiertas por categoría o divisa: acciones, ETF, cripto, opciones, depósitos y activos manuales (list_positions, list_liabilities)
  • Instantáneas históricas y desglose diario de posiciones (get_snapshots, get_snapshot_detail)
  • Rendimiento por periodo, curvas ponderadas por dinero y ganancias diarias por activo (get_performance, get_daily_earnings)
  • Dividendos, planes recurrentes, historial de operaciones y proyecciones FIRE

Herramientas de escritura (interruptor independiente)

  • Desactivadas por defecto: activar la lectura nunca habilita la escritura automáticamente.
  • Confirmación en dos pasos: la primera llamada devuelve una vista previa legible y un código temporal. El cambio solo se aplica cuando apruebas la vista previa y el agente envía la segunda llamada con ese código.
  • Permite registrar operaciones, ajustes de posición, activos, deudas, planes y deshacer cambios, con registro integrado en Ajustes.

Ejemplos de preguntas

  • «¿Cuál es mi patrimonio neto actual en EUR y cuánto ha variado mi cartera este mes?»
  • «¿Qué posiciones han aportado más a mis ganancias o pérdidas en los últimos 90 días?»
  • «¿Cuántos ingresos anuales estimados tengo por dividendos y depósitos a plazo, y qué porcentaje de mis gastos FIRE cubren?»
  • «Muéstrame la vista previa para añadir 10 acciones de AAPL a 225 $ hoy y espera mi confirmación antes de guardarlo.»

Modelo de seguridad

  • Solo localhost: escucha únicamente en 127.0.0.1, nunca expuesto a tu red local ni a Internet.
  • Respeta el bloqueo de la app: las peticiones se bloquean cuando WorthTrail está bloqueado.
  • Protección frente a inyección de prompts: las herramientas indican a los agentes que traten nombres, símbolos, etiquetas y notas estrictamente como datos, nunca como instrucciones.
  • Revocación inmediata: desactiva el interruptor, cambia el puerto o restablece el token del Llavero para desconectar todos los clientes al instante.
