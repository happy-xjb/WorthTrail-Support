Model Context Protocol · macOS · Endast localhost

Fråga AI om din nettoförmögenhet — utan att ladda upp den till molnet.

WorthTrail för Mac innehåller en inbyggd lokal MCP-server (Model Context Protocol) över Streamable HTTP. Anslut Claude Code, Claude Desktop, Codex eller annan kompatibel klient för att fråga om portföljen och logga ändringar först efter godkänd förhandsgranskning.

Anslutningsspecifikationer

Egenskap Värde
Transport Streamable HTTP (endast lokal loopback)
Standardadress http://127.0.0.1:47821/mcp (port kan ändras i Inställningar, 1024–65535)
Autentisering Authorization: Bearer <token> (lagrad i macOS Nyckelhanterare; kan återställas när som helst)
Tillgänglighet Körs endast när WorthTrail är öppet på Mac och Agentåtkomst är aktiverad
Pris Ingår i gratisplanen (ingen betalvägg på MCP; gränsen på 10 poster gäller nya tillgångar)

Så ansluter du

Öppna WorthTrail på Mac → Inställningar → Agentåtkomst, aktivera lokal agentåtkomst och kopiera din personliga installationsprompt eller Bearer-token.

Claude Code

claude mcp add --transport http --scope user worthtrail http://127.0.0.1:47821/mcp \
  --header "Authorization: Bearer YOUR_TOKEN"

Claude Desktop (~/.claude.json)

{
  "mcpServers": {
    "worthtrail": {
      "type": "http",
      "url": "http://127.0.0.1:47821/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Codex (~/.codex/config.toml)

[mcp_servers.worthtrail]
url = "http://127.0.0.1:47821/mcp"
http_headers = { "Authorization" = "Bearer YOUR_TOKEN" }

Vad AI-agenter kan fråga om och göra

Läsverktyg (aktiva när Agentåtkomst är på)

  • Aktuell nettoförmögenhet, totala tillgångar, skulder, anskaffningsvärde och dagens förändring (get_net_worth)
  • Öppna positioner per kategori eller valuta: aktier, ETF:er, krypto, optioner, bundet sparande och manuella tillgångar (list_positions, list_liabilities)
  • Historiska ögonblicksbilder och daglig uppdelning per innehav (get_snapshots, get_snapshot_detail)
  • Periodprestanda, pengar-viktade avkastningskurvor och daglig vinst per innehav (get_performance, get_daily_earnings)
  • Utdelningar, sparplaner, transaktionshistorik och FIRE-prognoser

Skrivverktyg (separat reglage)

  • Avstängda som standard — att slå på läsåtkomst ger aldrig automatiskt skrivåtkomst.
  • Tvåstegsbekräftelse: första anropet returnerar en läsbar förhandsgranskning och en tillfällig kod. Ändringen sparas först när du godkänner och agenten skickar andra anropet med koden.
  • Stöder affärer, positionsjusteringar, tillgångar, skulder, sparplaner och ångra — med inbyggd ändringslogg i Inställningar.

Exempelfrågor du kan ställa

  • ”Vad är min nuvarande nettoförmögenhet i SEK och hur mycket har portföljen förändrats denna månad?”
  • ”Vilka innehav har bidragit mest till min vinst eller förlust de senaste 90 dagarna?”
  • ”Hur mycket årlig utdelning och ränta väntas jag få och hur stor del av mina FIRE-utgifter täcker det?”
  • ”Förhandsgranska köp av 10 aktier i AAPL för $225 idag och vänta på mitt godkännande innan du sparar.”

Säkerhetsmodell

  • Endast localhost: lyssnar enbart på 127.0.0.1 — aldrig exponerad mot lokalt nätverk eller internet.
  • Respekterar applås: alla förfrågningar blockeras när WorthTrail är låst.
  • Skydd mot prompt-injektion: instruktioner anger tydligt att namn, symboler, taggar och anteckningar endast är data och aldrig kommandon.
  • Omedelbar återkallelse: stäng av reglaget, byt port eller återställ nyckelhanterartoken för att direkt koppla bort alla klienter.
