真实界面一览

克制清晰的排版，让每一笔资产和收益一目了然。

产品架构

为长期财富管理而生，而非嘈杂的消费流水记账。

把分散在各家券商、银行定存、理财、加密钱包和房产中的头寸统一归集，由你完全掌控数据。

01 / 隐私架构

本机 SwiftData + 私人 iCloud

所有持仓、快照与备注默认存在你的设备上，开启同步后仅存入你个人的 Apple CloudKit 私有数据库。开发者不运营存储你数据的服务器，零广告、零第三方分析 SDK。

02 / 全品类资产

跨市场投资与定期存款

支持美股、港股、A股、台股、ETF、基金、加密货币、期权、定期存款与大额存单、支持的部分银行理财产品、房产黄金及各类负债，多币种自动换算。

03 / 长期规划

FIRE、定投、拆股与报表

支持自定义年支出与提取率的 FIRE 进度及资产够用年限测算、定投计划、股票拆合调整、隐私小组件，以及 Excel 工作簿与 PDF 报告导出。

Model Context Protocol · macOS

Mac 版内置本地 MCP 服务，让 AI 安全读懂你的资产。

Mac 版 WorthTrail 内置本地 Streamable HTTP MCP 服务（http://127.0.0.1:47821/mcp），使用 Keychain 存储的 Bearer Token 鉴权。连接 Claude Code、Claude Desktop 或 Codex 后，可直接用日常语言询问净资产、持仓、阶段收益、分红与 FIRE 进度。

安全机制：默认关闭、仅监听本机回环地址；读写权限分离，任何写入都必须先返回预览与确认码，经你同意后才会执行，全程保留变更日志。
