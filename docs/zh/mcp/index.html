Model Context Protocol · macOS · 仅限本机回环

让 AI 回答你的净资产问题，而无需把账本上传到云端。

Mac 版 WorthTrail 内置基于 Streamable HTTP 的本地 MCP（Model Context Protocol） 服务。连接 Claude Code、Claude Desktop、Codex 或其他兼容客户端，即可自然语言查询资产，并可在明确预览确认后记录变更。

获取 Mac 版 WorthTrail 查看常见问题

连接规格

属性 说明
传输协议 Streamable HTTP（仅监听本机回环地址）
默认地址 http://127.0.0.1:47821/mcp（可在设置中修改端口，1024–65535）
鉴权方式 Authorization: Bearer <token>（存于 macOS 钥匙串，随时可重置）
运行条件 仅在 Mac 版 WorthTrail 处于打开状态且开启「Agent 访问」时运行
收费说明 免费版即完整包含（MCP 无付费墙；新增资产仍沿用免费版 10 项上限）

如何连接

打开 Mac 版 WorthTrail → 设置 → Agent 访问，开启本地 Agent 访问，然后复制专属配置提示词或 Bearer Token。

Claude Code

claude mcp add --transport http --scope user worthtrail http://127.0.0.1:47821/mcp \
  --header "Authorization: Bearer YOUR_TOKEN"

Claude Desktop (~/.claude.json)

{
  "mcpServers": {
    "worthtrail": {
      "type": "http",
      "url": "http://127.0.0.1:47821/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Codex (~/.codex/config.toml)

[mcp_servers.worthtrail]
url = "http://127.0.0.1:47821/mcp"
http_headers = { "Authorization" = "Bearer YOUR_TOKEN" }

AI 助手可以查询与执行什么

只读工具（开启 Agent 访问后可用）

  • 当前净资产、总资产、负债、持仓成本与今日变动（get_net_worth）
  • 按分类或币种列出全部持仓，含股票、ETF、加密货币、期权、定存与自定义资产（list_positions、list_liabilities）
  • 历史快照与单日持仓明细（get_snapshots、get_snapshot_detail）
  • 阶段投资表现、资金加权收益曲线与按标的拆分的每日盈亏（get_performance、get_daily_earnings）
  • 分红、定投计划、交易流水与 FIRE 测算

写入工具（需单独手动开启）

  • 默认关闭——开启只读访问绝不会自动开放写入权限。
  • 两步确认机制：首次工具调用仅返回可读预览与短时效确认码；只有你核对同意后，由 AI 携带该确认码发起第二次调用才会真正写入。
  • 支持记录交易、持仓调整、新增资产/负债、定投计划及撤销操作，并在设置内保留完整变更日志。

可以直接这样提问

  • “我目前的净资产折合人民币是多少？这个月整体变化了多少？”
  • “过去 90 天里，哪几项持仓对我的盈亏贡献最大？”
  • “预计我今年能收到多少税后股息和定存利息？能覆盖多少比例的 FIRE 年支出？”
  • “先帮我预览今天以 225 美元买入 10 股 AAPL 的记录，等我确认后再写入。”

安全模型

  • 仅绑定本机回环：仅监听 127.0.0.1，不向局域网或公网暴露。
  • 遵循应用锁状态：当 WorthTrail 处于锁屏状态时，所有请求都会被拒绝。
  • 提示词注入防护：工具说明会明确要求 AI 将用户录入的名称、代码、标签和备注严格视为纯数据，绝不当作指令执行。
  • 随时一键撤销：关闭开关、修改端口或重置钥匙串 Token，即可立即断开全部客户端连接。
