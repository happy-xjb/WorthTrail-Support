隐私政策

WorthTrail 的设计原则是让你的完整净资产始终留在你的设备与个人 iCloud 中，绝不经过开发者服务器。

01

保存在你设备上的数据

WorthTrail 使用 Apple SwiftData 在你的设备上本地存储资产、数量、持仓成本、负债、加减仓记录、分红、定投计划、标签、备注、设置与历史快照。

开发者不运营任何接收、存储或查看你资产数据的后端服务器，使用 WorthTrail 也无需注册账号。

02

可选的个人 iCloud 私有同步

当你开启 iCloud 同步时，资产数据仅通过与你 Apple 账号绑定的个人 Apple CloudKit 私有数据库进行同步。

开发者无法访问你的 CloudKit 私有数据库。同步数据的传输与存储安全遵循 Apple iCloud 的安全与隐私机制。

03

行情与汇率数据服务商

当你搜索标的或刷新行情与汇率时，WorthTrail 仅会将必要的搜索词、标的代码、数据源标识和目标币种发送给你在 设置 > 数据源与状态 中启用的服务商。

这些服务商（可能包括 Yahoo Finance、微牛、新浪财经、Binance、OKX、CoinGecko、CoinMarketCap、TWSE、ExchangeRate-API 及支持的部分银行理财数据源）可能接收你的 IP 地址与常规网络信息，并依照各自隐私政策处理。WorthTrail 绝不会向任何行情服务商发送你的持仓数量、成本价或账户余额。

04

本地 OCR 识别、小组件、备份与诊断文件

截图批量导入（OCR）：你选择用于批量导入的截图完全通过 Apple 本地 Vision 框架在设备上识别，不会上传至 WorthTrail 服务器。

主屏幕小组件：小组件仅通过 App 私有 App Group 容器读取展示所需的汇总信息；隐私小组件不包含任何资产金额。

本地备份与诊断文件：带密码保护的本地备份在导出前即于设备本地加密。可选的 .wtdiag 诊断文件仅在你主动发起排查导出时生成，并在离开 App 前完成加密。

05

Mac 本地 MCP 服务

Mac 版 WorthTrail 提供可选的本地 Streamable HTTP MCP 服务，严格绑定本机回环地址 127.0.0.1，并使用存储在 macOS 钥匙串中的 Bearer Token 鉴权。该服务默认关闭，默认只读，写入需单独开启并经过预览与确认码两步校验。

如果你主动将本地 MCP 服务连接到外部 AI 客户端（如 Claude Code、Claude Desktop 或 Codex），你指示该 AI 客户端查询的资产数据将遵循该 AI 客户端及模型服务商自身的隐私政策。

06

无广告、无追踪、应用内购买与应用锁

WorthTrail 不包含任何广告、跨应用追踪代码或第三方分析 SDK。

应用内购买与订阅完全由 Apple StoreKit 处理。Face ID 与触控 ID 由 iOS/macOS 系统处理，WorthTrail 无法接触生物识别信息。应用密码锁仅在设备上保存加盐加密哈希值。

07

数据删除、政策更新与联系我们

卸载 WorthTrail 即可彻底移除设备上的本地数据；iCloud 同步数据可在 Apple iCloud 设置中随时删除；自行导出的备份、Excel、PDF 或诊断文件可在其保存位置删除。

当 App 行为发生变化时，本隐私政策可能会相应更新。如有任何隐私问题，请通过支持页面联系我们，或发送邮件至 support@worthtrail.app。
