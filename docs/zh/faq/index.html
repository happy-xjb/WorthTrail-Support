产品说明与答疑

常见问题（FAQ）

关于隐私架构、资产覆盖、收费方式、分红与 FIRE 计算以及 Mac MCP 服务的直接解答。

WorthTrail 需要绑定银行卡或券商账号吗？

不需要。WorthTrail 专门为不想授权银行或券商登录凭证的用户设计。你可以直接记录持仓、现金、定存和负债，公开市场的股价、币价和汇率会自动更新。

我的资产数据存在哪里？开发者能看到吗？

所有数据默认使用 Apple SwiftData 保存在你的设备本地。开启 iCloud 同步后，同步数据仅存在你个人的 Apple CloudKit 私有数据库中。开发者不运营接收你资产数据的服务器，App 内没有任何广告或第三方分析 SDK。

怎么收费？支持一次性买断吗？

支持买断。免费版开放全部功能，可记录最多 10 项（资产、现金与负债合计）。Pro 仅解除 10 项数量限制：中国大陆参考价为 ¥8/月、¥38/年、¥88 永久买断（美区 $0.99/月、$5.99/年、$12.99 永久买断），具体以 App Store 实际显示为准。

支持哪些资产类型、市场和币种？

支持美股、港股、A股、台股及全球股票、ETF、基金、加密货币、期权、定期存款与大额存单、支持的部分银行理财产品、现金、房产/黄金/债券等自定义资产，以及房贷、消费贷和信用卡等负债。所有外币资产会自动按汇率折算为你设定的主币种。

行情数据来自哪里？

你可以在 App 的设置 > 数据源与状态中自由开启、关闭和排序数据源，包括 Yahoo Finance、新浪财经、微牛、Binance、OKX、TWSE、ExchangeRate-API 及支持的部分银行理财数据源。查询行情时仅会向你启用的数据源发送必要的代码与币种请求。

支持分红、定投、再平衡和 FIRE 测算吗？

全部支持。包括分红日历、税后被动收入与集中度分析、定投计划、目标配置与再平衡测算、拆股自动调整，以及可自定义年支出、提取率和规划年龄的 FIRE 进度与资产够用多久估算。

Mac 版的本地 MCP 服务有什么用？安全吗？

Mac 版内置本地 Streamable HTTP MCP 服务（http://127.0.0.1:47821/mcp），支持 Claude Code、Claude Desktop、Codex 等客户端用自然语言查询净资产、持仓、阶段收益、分红与 FIRE 进度。该服务默认关闭，采用 Keychain 存储的 Bearer Token 鉴权，读写权限分离，任何写入都必须先返回预览与确认码、经你同意后才会执行。详情见 Mac MCP 接入指南。

支持导出和备份吗？

支持。你可以导出带密码加密的本地备份文件并随时恢复，也可以导出 Excel（.xlsx）工作簿和 PDF 报告，方便归档或进一步分析。

支持哪些设备和系统？

支持 iPhone、iPad 与 Mac，可在 Apple App Store 下载，内置 45+ 种语言。目前暂不提供 Android 或网页版。
