Model Context Protocol · macOS · Localhost uniquement

Interrogez une IA sur votre patrimoine — sans l’envoyer dans le cloud.

WorthTrail pour Mac intègre un serveur MCP (Model Context Protocol) local en Streamable HTTP. Connectez Claude Code, Claude Desktop, Codex ou tout client compatible pour consulter votre portefeuille et enregistrer des opérations uniquement après aperçu et approbation.

Obtenir WorthTrail sur Mac Lire la FAQ

Spécifications de connexion

Propriété Valeur
Transport Streamable HTTP (boucle locale uniquement)
Adresse par défaut http://127.0.0.1:47821/mcp (port configurable dans Réglages, 1024–65535)
Authentification Authorization: Bearer <token> (stocké dans le Trousseau macOS ; réinitialisable à tout moment)
Disponibilité Actif uniquement lorsque WorthTrail est ouvert sur Mac et que l’Accès des agents est activé
Tarif Inclus dans la version gratuite (aucun mur payant sur MCP ; la limite de 10 éléments s’applique aux nouveaux actifs)

Comment se connecter

Ouvrez WorthTrail sur Mac → Réglages → Accès des agents, activez l’accès local et copiez votre prompt de configuration ou votre jeton Bearer.

Claude Code

claude mcp add --transport http --scope user worthtrail http://127.0.0.1:47821/mcp \
  --header "Authorization: Bearer YOUR_TOKEN"

Claude Desktop (~/.claude.json)

{
  "mcpServers": {
    "worthtrail": {
      "type": "http",
      "url": "http://127.0.0.1:47821/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Codex (~/.codex/config.toml)

[mcp_servers.worthtrail]
url = "http://127.0.0.1:47821/mcp"
http_headers = { "Authorization" = "Bearer YOUR_TOKEN" }

Ce que les agents IA peuvent consulter et faire

Outils de lecture (actifs dès l’activation)

  • Patrimoine net actuel, total des actifs, dettes, prix de revient et variation du jour (get_net_worth)
  • Positions ouvertes par catégorie ou devise : actions, ETF, crypto, options, dépôts et actifs personnalisés (list_positions, list_liabilities)
  • Instantanés historiques et détail quotidien des positions (get_snapshots, get_snapshot_detail)
  • Performances sur période, courbes de rendement pondéré par les capitaux et gains quotidiens par actif (get_performance, get_daily_earnings)
  • Dividendes, plans programmés, historique des transactions et projections FIRE

Outils d’écriture (interrupteur séparé)

  • Désactivés par défaut — activer la lecture n’active jamais l’écriture automatiquement.
  • Confirmation en deux étapes : le premier appel renvoie un aperçu lisible et un code temporaire. La modification n’est appliquée qu’après votre validation via un second appel portant ce code.
  • Permet d’enregistrer opérations, ajustements de position, actifs, dettes, plans et annulations — avec journal intégré dans Réglages.

Exemples de questions à poser

  • « Quel est mon patrimoine net actuel en EUR et quelle a été son évolution ce mois-ci ? »
  • « Quelles positions ont le plus contribué à mes gains ou pertes sur les 90 derniers jours ? »
  • « Quel montant annuel de dividendes et d’intérêts de dépôts à terme vais-je percevoir, et quelle part de mes dépenses FIRE couvre-t-il ? »
  • « Prépare un aperçu pour l’ajout de 10 actions AAPL à 225 $ aujourd’hui et attends ma confirmation avant d’enregistrer. »

Modèle de sécurité

  • Écoute localhost uniquement : lié strictement à 127.0.0.1, inaccessible depuis votre réseau local ou Internet.
  • Respect du verrouillage : toute requête est bloquée lorsque WorthTrail est verrouillé.
  • Protection contre l’injection de prompt : les outils indiquent explicitement aux agents de traiter noms, symboles, étiquettes et notes comme des données pures, jamais comme des instructions.
  • Révocation instantanée : coupez l’interrupteur, changez le port ou réinitialisez le jeton du Trousseau pour déconnecter immédiatement tous les clients.
