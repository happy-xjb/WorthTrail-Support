Model Context Protocol · macOS · Kun localhost

Spørg AI om din formue — uden at uploade den til skyen.

WorthTrail til Mac indeholder en indbygget lokal MCP-server (Model Context Protocol) via Streamable HTTP. Forbind Claude Code, Claude Desktop, Codex eller en anden kompatibel klient for at forespørge din portefølje og kun registrere ændringer efter godkendt forhåndsvisning.

Hent WorthTrail til Mac Læs FAQ

Forbindelsesspecifikationer

Egenskab Værdi
Transport Streamable HTTP (kun lokal loopback)
Standard-endpoint http://127.0.0.1:47821/mcp (port kan indstilles i Indstillinger, 1024–65535)
Godkendelse Authorization: Bearer <token> (gemt i macOS Nøglering; kan nulstilles når som helst)
Tilgængelighed Kører kun mens WorthTrail er åben på Mac og Agentadgang er slået til
Pris Inkluderet i gratisplanen (ingen betalingsmur på MCP; 10-postersgrænsen gælder nye aktiver)

Sådan forbinder du

Åbn WorthTrail på Mac → Indstillinger → Agentadgang, slå lokal agentadgang til, og kopiér din opsætningsprompt eller Bearer-token.

Claude Code

claude mcp add --transport http --scope user worthtrail http://127.0.0.1:47821/mcp \
  --header "Authorization: Bearer YOUR_TOKEN"

Claude Desktop (~/.claude.json)

{
  "mcpServers": {
    "worthtrail": {
      "type": "http",
      "url": "http://127.0.0.1:47821/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Codex (~/.codex/config.toml)

[mcp_servers.worthtrail]
url = "http://127.0.0.1:47821/mcp"
http_headers = { "Authorization" = "Bearer YOUR_TOKEN" }

Hvad AI-agenter kan forespørge og udføre

Læseværktøjer (aktive når Agentadgang er slået til)

  • Aktuel formue, samlede aktiver, forpligtelser, kostpris og dagens ændring (get_net_worth)
  • Åbne positioner efter kategori eller valuta: aktier, ETF'er, krypto, optioner, tidsindskud og manuelle aktiver (list_positions, list_liabilities)
  • Historiske snapshots og daglig fordeling af beholdninger (get_snapshots, get_snapshot_detail)
  • Periodeafkast, pengevægtede afkastkurver og daglig indtjening pr. beholdning (get_performance, get_daily_earnings)
  • Udbytte, gentagne planer, transaktionshistorik og FIRE-fremskrivninger

Skriveværktøjer (separat tilvalg)

  • Deaktiveret som standard — læseadgang aktiverer aldrig skrivning automatisk.
  • Totrinsbekræftelse: første kald returnerer en læsbar forhåndsvisning og en kortlivet kode. Ændringen gemmes først, når du godkender og agenten sender andet kald med koden.
  • Understøtter handler, beholdningsjusteringer, aktiver, forpligtelser, planer og fortryd — med indbygget ændringslog i Indstillinger.

Eksempler på spørgsmål

  • ”Hvad er min nuværende formue i DKK, og hvor meget har porteføljen ændret sig denne måned?”
  • ”Hvilke beholdninger har bidraget mest til mit resultat de seneste 90 dage?”
  • ”Hvor meget årligt udbytte og rente forventes jeg at modtage, og hvor stor en del af mine FIRE-udgifter dækker det?”
  • ”Vis en forhåndsvisning for tilføjelse af 10 AAPL-aktier til $225 i dag og afvent min godkendelse.”

Sikkerhedsmodel

  • Kun localhost: lytter udelukkende på 127.0.0.1 — aldrig eksponeret på LAN eller internettet.
  • Respekterer applås: forespørgsler blokeres, når WorthTrail er låst.
  • Beskyttelse mod prompt-injektion: værktøjsinstruktioner beder agenter om udelukkende at behandle navne, symboler, tags og noter som data, aldrig som kommandoer.
  • Øjeblikkelig tilbagekaldelse: slå kontakten fra, skift port eller nulstil nøgleringstoken for straks at afbryde alle klienter.
